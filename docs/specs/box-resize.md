# 标注框像素缩放

选中当前图片的矩形框，在画布或标签列表中按 `H` 放大、`F` 缩小。
每条边默认移动 1 个原图像素，宽、高每次变化 2 像素，中心保持不变。

编辑菜单提供同名操作及“标注框缩放步长（像素）”，范围为 1～100。
步长随应用设置保存；旧设置缺失或无效时回退为 1。

## 操作限制

- 快捷键只在画布或标签列表获得焦点时生效。
- 输入框、图片列表、步长控件及对话框中不触发缩放。
- 绘制、鼠标拖动、右键复制移动期间不执行。
- 长按不连续缩放，鼠标悬停框不是操作目标。
- 任何一边越界，或缩小后宽、高小于 1，整次操作被拒绝。
- 拒绝操作不修改坐标、不发出移动信号，也不新增未保存状态。
- 标签名、颜色、困难标记、顶点顺序和选中对象保持不变。
- 切换图片后旧框引用不能被修改。

## 坐标和保存

步长按原图坐标计算，与画布显示比例、屏幕 DPI 无关。
保留浮点坐标，在保存时沿用原有格式量化规则。

第一版保留现有保存行为：VOC 和 YOLO 的左、上边界至少为 1；
CreateML 的左、上边界可以为 0。右、下边界最多为图片宽、高。
VOC/YOLO 坐标为 1 的框不能再向外放大；状态栏显示已到达图片边界。

成功时发出一次 `shapeMoved`，沿用未保存状态和切图自动保存流程。
不新增缩放撤销；现有恢复已删除标签和图片的快捷键保持原意。

## 实现和验证

- `libs/box_geometry.py`：无 Qt 依赖的计算及验证，返回 `ResizeResult`。
- `Canvas.resize_selected_shape`：校验状态，一次性替换四个 `QPointF`。
- `MainWindow`：菜单、快捷键焦点限制、格式边界和步长设置。
- `tests/test_box_resize.py`：几何和画布原子性、信号、元数据测试。
- `tests/test_box_resize_workflow.py`：真实 Qt 事件、设置和三种格式往返测试。

更新本地化字符串后，按项目原有构建方式重新生成 Qt 资源：

```powershell
python -m PyQt5.pyrcc_main resources.qrc -o libs/resources.py
```

`libs/resources.py` 是 Git 忽略的构建产物。运行测试需要 PyQt5 和 lxml。
测试使用临时图片、临时设置和临时目录，避免改写用户设置。
